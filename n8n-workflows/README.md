# n8n Workflows

This folder contains the exported n8n workflow files for the AI Supplier & Quote Management System.

## Planned Workflows
- Purchase request validation
- Supplier matching
- RFQ email sending
- Supplier quotation processing
- AI quotation data extraction
- Quotation comparison
- Human approval before Purchase Order generation

## Notes
- Export workflows as JSON before committing them.
- Do not include API keys, passwords, or credentials in exported files.
- Test workflows with synthetic data before using real supplier information.
