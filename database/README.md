# Database

This folder contains the database design and setup files for the AI Supplier & Quote Management System.

## Planned Data Entities
- Purchase Requests
- Suppliers
- Supplier Quotations
- Quotation Items
- Approval Records
- Purchase Orders

## Planned Database
PostgreSQL is the planned database system.

## Guidelines
- Document table names, fields, data types, and relationships.
- Use synthetic data for development and testing.
- Never store API keys, passwords, or credentials in database scripts.
- A Purchase Order must not be generated before explicit human approval.
